## About

I build full-stack web applications end to end — responsive frontends in **React** and **Next.js**, REST APIs in
**Node.js** and **Express**, and data layers on **MongoDB**. Lately I've been building with **LLM APIs**
(Groq, OpenAI, Gemini), turning them into tools people can actually use rather than demos.

Comfortable across the whole stack: frontend, backend, database and deployment. Strong foundation in
**DSA, OOP, DBMS and System Design**.

**Currently exploring** — TypeScript in depth, System Design, and LLM tooling.
