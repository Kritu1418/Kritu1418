I build full-stack web applications end to end — responsive frontends in **React** and **Next.js**, REST APIs in
**Node.js** and **Express**, and data layers on **MongoDB**. Lately I've been building with **LLM APIs**
(Groq, OpenAI, Gemini), turning them into tools people actually use rather than demos.

Comfortable across the whole stack — frontend, backend, database and deployment — with a strong foundation in
**DSA, OOP, DBMS and System Design**.

> [!TIP]
> **Currently** — going deeper on TypeScript and System Design, and building AI tooling on top of LLM APIs.
